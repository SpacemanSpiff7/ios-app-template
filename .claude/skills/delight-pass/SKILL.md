description: Add purposeful native feedback after a flow works. Use for requested haptics, motion or interaction polish.
argument-hint: <screen or flow>

1. Read DESIGN.md, DELIGHT.md and the task's interaction evidence.
2. Identify the user consequence that needs feedback. Prefer a native control response, numeric transition or
   matching sensoryFeedback over a new wrapper/effect. A signature animation is optional.
3. Apply the smallest change within the requested scope; honor Reduce Motion.
4. Inspect the resulting normal/AX3 light/dark screens and available interaction. Report haptic/physical checks
   separately. Run the appropriate gate and fix introduced regressions.
